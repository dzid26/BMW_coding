My NCS Dummy settigs for bmw E82.  

Some of the TRC from this repo needs binary data definition from the Releases to pick up the actual value I use. 

The binary data needs to be downloaded and placed in `C:\NCSEXPER\DATEN\E89`.  First create backup of `C:\NCSEXPER\DATEN\E89` to avoid reinstallation of ncsexpert.
